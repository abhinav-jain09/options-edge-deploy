# Dev Rithmic Kafka stream

The collector runs in the dev Kubernetes namespace options-edge and publishes canonical Avro depth frames to raw.rithmic.es.depth. The existing es-spx-align service reads that topic and its existing global basis store, then writes options.rithmic.es-depth-spx. The feed gateway consumes the display topic and sends rithmic-liquidity events over its existing authenticated WebSocket. The web renders those events on the existing Order chart transforms.

There is no laptop runtime or SSH market-data tunnel, no collector data HTTP endpoint, no Rithmic HTTP proxy in web, and no liquidity polling in the browser. The old RITHMIC_DEPTH_URL/TOKEN env entries are removed from both mirrored web patches. The dev-only alignment and gateway flags are enabled together; the init schema provisioner's flag mirrors the alignment main container. Generated service slices are regenerated from the monolithic dev overlay. Production manifests/flags stay unchanged.

Collector credentials are injected only into its pod from Kubernetes Secret rithmic-depth-bridge. Kafka/Schema Registry addresses come from the existing dev ConfigMap. The collector's Jenkins pipeline binds both source and contracts revisions, provisions only the new topics/schemas, builds and pins its image digest, retires the superseded Mac collector/tunnel, then waits for acknowledged-book readiness. It exposes no Service or listening market-data port.

Build gateway with option-edge-feed-gateway (Jenkinsfile), not feed-gateway-deploy (Jenkinsfile.deploy, the retired host-jar topology). Build alignment through options-edge-processing with BUILD_TARGET=options-edge-es-spx-align-service. Build web through options-edge-web-deploy. Use the existing service-deploy job for separate web/gateway/alignment workload rollouts, binding the exact deployment main SHA and each image receipt. On the laptop CI agent select /Users/abhinav/.kube/jenkins-deployer-dev-remote.kubeconfig explicitly: its default localhost kubeconfig is stale. No production rollout is requested.

Actual pod login, canonical Kafka records, gateway WebSocket events, chart gestures, stale/disconnect behavior and the same-contract Bookmap comparison are acceptance gates, not implied by source checks. Feed is labelled Rithmic Test. Bugzilla is skipped at the owner's request.
